# Rake Multiplayer — аудит v1.0.18

Отчёт шести независимых аудитов (сеть/авторитет, AI, бой/смерть/лут, игроки/камера/ввод,
мир/патчи, архитектура/UI/тесты). Каждый агент читал исходники мода, декомпил ванилы
(`Assembly-CSharp.decompiled.cs`) и `Rake/BepInEx/LogOutput.log`.

Статус: `[ ]` — не исправлено, `[x]` — исправлено, `[~]` — исправлено частично / требует проверки.

## P0 — ломает игру

- [ ] **P0-1. PvP по клиентам невозможен.**
  `Components/NetworkedPlayer.cs:178-180` выключает `CharacterController` и
  `Rigidbody.detectCollisions`; `Components/RemotePlayerVisual.cs:196-197` уничтожает
  коллайдеры заглушек; другого хитбокса нет. `Core/ProjectileSystem.cs` ищет жертву через
  `hit.collider.GetComponentInParent<NetworkedPlayer>()`.
  Следствие: хост не попадает в клиента, клиент — в клиента. Работает только «клиент → хост».
  `-deathtest` стреляет в хоста, поэтому не ловится.
  Фикс: trigger-капсула на прокси, не мешающая движению.

- [ ] **P0-2. Steam: первый клиент получает PlayerId = 1 (ID хоста).**
  `Networking/SteamTransport.cs:29` (`_nextConn = 0`), `:96`, `Core/RakeNetworkManager.cs:361`
  (`connectionId + 1`). В LAN Telepathy начинает с 1.
  Следствие: адресные пакеты клиенту не доходят (`playerId <= 1`), `FindPlayerTransform(1)`
  возвращает хоста, урон по клиенту бьёт хоста, хост исчезает у клиента.
  Фикс: серверный счётчик id, начиная с 2; «хост» — не по `id <= 1`.

- [ ] **P0-3. Клиент может убить любого и заспавнить лут.**
  `RakeNetworkManager.cs:482` → `HandleServerPlayerDied` без `connectionId`;
  `Core/PlayerDeathSystem.cs:106-137` доверяет `PlayerId/Position/WeaponIds[]`.
  `PlayerDied{PlayerId=1}` убивает хоста. Лут — в любой точке, до 12 предметов.
  `PlayerRagdollRequest` (`RakeNetworkManager.cs:577-586`) так же доверяет `PlayerId`.

- [ ] **P0-4. Хост не рассылает свои подборы предметов.**
  `Patches/GamePatches.cs:451` — `obj as Item` на `GameObject` (ванила зовёт
  `Destroy(gameObject)`), поэтому `MarkConsumed` не вызывается; `Patches/ItemPickupSync.cs:139`
  всегда `return`. У клиентов предмет остаётся, E → `NotFound`, объект неподбираем навсегда.

- [ ] **P0-5. Консоль не изолирует ввод.**
  `Core/DebugConsole.cs:989-1024` морозит только `CameraMouseLook` и `PlayerMovement`.
  Параллельно работают: `WeaponManager.Update` (1/W/V/T/M/C/B), `FPSCamera.Update` (E —
  подбор), `FPSController.Update` (I — инвентарь, F — фонарь), оружие (Fire1), `GamePauseMenu`
  (Escape → timeScale = 0). Курсор не разблокирован, кнопки-подсказки некликабельны.

- [ ] **P0-6. Меню F1 не забирает ввод.**
  `UI/MultiplayerMenu.cs:254-271` (`ToggleMenu`) не трогает `Cursor`/`PlayerInputLock`
  (в `OpenMenu` — трогает, `:249-250`). Кнопки некликабельны, камера крутится, WASD/ЛКМ
  действуют. `_startGameSent` сбрасывается только в `OnLeaveLobby` (`:445`) → второй матч
  из лобби не стартует.

## Архитектурная критика

1. `RakeNetworkManager` — god class на ~3000 строк: транспорт, роутинг, валидация, игра,
   эффекты. Из этого вытекают NET-1..NET-4, NET-10, NET-12.
2. Нет per-connection объекта (`PeerConnection { ConnId, PlayerId, SteamId, IsHost,
   RateBudget, RakeRole }`); идентичность выводится арифметикой `conn + 1`, права —
   эвристиками. Из этого P0-2, P0-3, NET-2.
3. Пакетный слой без версии, схемы и бюджета доверия: дыры в `PacketType`, строки без
   границ, нет rate-limit, разные лимиты у LAN и Steam.
