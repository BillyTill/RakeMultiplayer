# Rake Multiplayer 1.1.25-alpha.1-Main

Windows x86 · Rake (2015) · протокол **4** · 2026-11-20

Альфа-сборка после аудита реализации против спецификации механик
(`docs/audit/2026-11-20-mechanics-vs-implementation.md`). Перед игрой обновите мод на
**всех** машинах: клиент со старой сборкой хост отвергнет по версии протокола.

## Главное

- **Одиночная игра больше не ломается.** Мод не перехватывает камеры, приманку и
  капканы без подключения — это был critical-баг: в SP нельзя было поставить камеру.
- **Темп атак ИИ Рейка.** После удара задача сразу становится `Flee`; тот же охотник не
  может быть ранен чаще раза в 9 с и в первые 2.5 с после вставания из рагдолла. Больше
  нет «ударил → ждёт, пока встанешь → бьёт снова».
- **Скип из трейлера** («пропустить ночь») теперь двигает фазу у всех: хост ставит
  переход в очередь, клиент отправляет `PhaseSkipRequest`. Раньше у клиента кнопка не
  делала ничего, а у хоста уровень менялся в обход фазы.
- **Смена фазы не рвёт тик.** Переход выполняется после кадра, а не внутри `Update`.
  Патроны и сработавшие капканы переживают рассвет; HP Рейка переносится между сценами;
  снапшот мира применяется ровно один раз на уровень.
- **Хост проверяет выстрелы.** Клиент сообщает оружие в руках (`PlayerState.WeaponId`),
  и сервер не даёт дробовику «объявить» снайперский выстрел на 200 урона.
- **Поздний вход.** Вошедший видит мёртвых мёртвыми, сломанные камеры сломанными и
  реальный остаток ящика камер.
- **Капканы.** Сработавший ванильный капкан остаётся потраченным и после рассвета.
- **Респавн** держит полные 25 м от Рейка (раньше порог молча снижался до 15).
- **Дробины** летят в круге 4.5°, а не в квадрате ~6.4° по диагонали.
- **Смерть во время загрузки** повторяется, а не оставляет тело с 1 HP.
- Консольные `tp` и `rake hit` в сессии работают только у хоста.

## Совместимость

- Протокол 4: сборки 1.1.23 и ниже несовместимы, хост откажет с понятным сообщением.
- Установщик: `RakeMultiplayerSetup.exe` (тихий режим `/silent "<папка игры>"`).
- Конфиг мода не перезаписывается.

## Известные ограничения

- Частично израсходованный ящик камер не переносит остаток через смену фазы.
- Бинокль (id 7) не выпадает из трупа: для него нет Item-класса.
- Здоровье по-прежнему клиент-авторитетно; непроверенная смерть просто не даёт лута.
